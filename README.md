# Harshini Portfolio

Responsive single-page portfolio for desktop, tablet and mobile.

## Files
- `index.html` — page structure and content
- `style.css` — complete responsive styling
- `script.js` — mobile menu, project switcher and small interactions

## Deploy on GitHub Pages
1. Put these three files in the root of your `harshini-portfolio-designer` repository.
2. Commit and push.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Wait for Pages to rebuild, then hard refresh the site.

## Images
This build intentionally uses the image files already hosted by your current GitHub Pages portfolio via absolute URLs. That means you do not need to upload a local `assets` folder for this version.

If you later want a fully self-contained repository, download the current portfolio images into `/assets/` and replace the absolute image URLs in `index.html` with local paths such as `assets/hero-default.png`.
